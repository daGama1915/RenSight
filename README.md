# Ren'Sight (Alpha v0.2.2)

An automated suite for extracting, visualizing, and surveying narrative structures in Ren'Py games.

**Ren'Sight** is a toolkit that bridges the gap between creative writing and data-informed design. It allows developers to "see" their story's logic and collect structured feedback from players without breaking the creative flow.

---

## Key Features
* **One-Click Pipeline:** Point the toolkit at your game directory and generate scripts, graphs, and surveys in one go.
* **Narrative Flux Visualization:** Generate directed graphs (PNG/SVG/HTML) of your story’s labels, menus, and choices.
* **Survey Automation:** Automatically build TXT/HTML/Markdown questionnaires based on actual game choice points.
* **Non-Blocking UI:** A multi-threaded GUI that keeps the application responsive during heavy processing.
* **Narrative Analysis:** (Coming in v0.3) Analyze player feedback with both mathematical models and AI.
